# وب‌سایت آموزشگاه فنی و حرفه‌ای آزاد ماهریار (Maheryar Academy)

وب‌سایت رسمی و وب‌اپلیکیشن (PWA) آموزشگاه فنی و حرفه‌ای آزاد **ماهریار** با رویکرد مدرن مهارتی، تجربه کاربری روان (UI/UX ایرانی)، استانداردهای سئو، و ساختار کاملاً واکنش‌گرا (Mobile-First).

---

## 🌟 ویژگی‌های کلیدی پیاده‌سازی شده:

- **طراحی UI/UX اختصاصی و ایرانی**: بر پایه پالت رنگی رسمی لوگوی آموزشگاه ماهریار (ترکیب بنفش سلطنتی `#554596` و ارکیده `#a56baa` با رنگ‌های مکمل طلایی و زمردی) و تایپوگرافی اصیل با فونت **IranSansX**.
- **نصب پکیج‌ها بدون وابستگی به CDN**: کلیه ملزومات از جمله کتابخانه‌های `lucide` و `swiper` از طریق **NPM** نصب شده و بدون هیچ CDN خارجی اجرا می‌شوند.
- **سئو فنی و معنایی پیشرفته (Advanced Technical SEO)**:
  - استفاده از ساختار تگ‌های معنایی HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
  - داده‌های ساختاریافته **Schema.org (JSON-LD)** شامل اسکیماهای `VocationalSchool`، `EducationalOrganization`، `Course` و `FAQPage`.
  - متاتگ‌های استاندارد OpenGraph، Twitter Card، Canonical و Viewport.
- **وب‌اپلیکیشن پیش‌رونده (PWA)**:
  - فایل `manifest.json` استاندارد به زبان فارسی با جهت راست‌به‌چپ (RTL)، آیکون‌ها، رنگ پوسته و میانبرها.
  - سرویس ورکر اختصاصی (`sw.js`) جهت کش هوشمند دارایی‌ها، عملکرد آفلاین و تسریع بارگذاری مجدد.
  - منوی ناوبری چسبان در پایین صفحه (Bottom Dock Navigation) مخصوص کاربران موبایل.
  - پنجره هوشمند پیشنهاد نصب اپلیکیشن ماهریار (Install Prompt Toast).
- **معرفی دوره‌ها و رشته‌های فعال**:
  - فیلتر آنی دوره‌ها براساس رشته (فناوری اطلاعات و AI، امور مالی و حسابداری، پوشاک و خیاطی، نرم‌افزارهای مهندسی، صنایع دستی و بافت).
  - کارت‌های جامع دوره با اطلاعات ساعت، استاد، مدرک بین‌المللی فنی‌حرفه‌ای و شرایط اقساطی.
- **اطلاعات تماس و شعب**:

## 🚀 نحوه راه‌اندازی و توسعه:

۱. کلون کردن مخزن:
```bash
git clone https://github.com/roseshayan/maheryar_academy.git
cd maheryar
```

۲. نصب وابستگی‌ها و همگام‌سازی دارایی‌های محلی:
```bash
npm install
```

۳. ساخت دارایی‌های محلی (در صورت نیاز):
```bash
npm run build
```

۴. اجرا در سرور لوکال Laragon:
پروژه مستقیماً در مسیر `c:\laragon\www\maheryar` قرار دارد و از طریق آدرس `http://localhost/maheryar` یا دامنه مجازی `http://maheryar.test` در دسترس است.
